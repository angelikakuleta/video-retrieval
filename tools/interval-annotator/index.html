Duration [s] How long an annotation may last. Masks are not checked - the intro and the closing credits have whatever length they have.

Minimum 1.25 s is the frame sampling step of the pipeline. A shorter annotation can fall between two sampled frames, so nothing would ever find it.

Maximum 15 s is the point above which a described event spreads over several segments - then "the correct answer" stops being one fragment and the measure becomes arbitrary.

Adding an annotation outside the range is refused; a row that drifts outside it while being edited is marked, and the counter below the form says how many there are. Change either field to work with different limits. -
Tag vocabulary

Free-form labels on a row - the tool attaches no meaning to any of them. Every tag used is remembered in this browser and suggested afterwards. Renaming updates the rows that carry it; removing takes it off them too. Tags go out in the tags column of the CSV, comma separated.

    No tags yet. Add one here, or type one on a row.

    Format: id;type;start;end;desc;tags - semicolon separator, dot decimal, UTF-8, one header line. File name <episode>_intervals.csv.

    type is event (an annotation) or mask (intro, closing credits - no annotation may overlap one). A file with no type column imports as annotations.

    tags is a comma separated list of free-form labels (wymaga_osoby,reshoot), empty when the row has none. Only a column named tags is read; a file without it imports untagged. Spaces in a tag become _.

    id is taken from the file exactly as it stands and never renamed. Its last part says where the row came from: tbbt_s01e01_d97650 was imported and carries the source id 97650, office_s02e03_001 was created here, office_s02e03_m001 is a mask. A row whose id is already on the list is skipped and reported - keeping ids intact is what makes it possible to tell later which annotations were removed here.

    Importing onto a non-empty list offers to replace it; cancelling adds the rows instead.
